# PORTA-STUDIO

An editorial design-studio portfolio built with React, TypeScript, and Vite. The page includes responsive navigation, a project showcase, service list, stats, FAQ accordion, and contact footer.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The project is deployed on Vercel at https://porta-studio-six.vercel.app/. Project imagery currently uses remote, legally usable placeholder assets; replace them with licensed brand assets in `src/App.tsx` before publishing.
